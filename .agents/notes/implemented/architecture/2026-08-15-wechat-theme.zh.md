# Agent Note：内置微语展示主题

状态：已实现

[English](2026-08-15-wechat-theme.md) | 中文

## 问题

桌面发行版需要一个可选、熟悉且以聊天为中心的视觉方案，同时保留 DeepSeek Harness 官方交互模型、设置持久化机制以及原有浅色／深色／跟随系统主题。如果只在具体页面临时改样式，会绕过主题运行时、导致启动闪烁，并让功能包散落大量颜色字面量。

## 决策

`wechat` 作为第四个可持久化的内置主题偏好，并继续充当稳定的兼容 id；用户看到的名称改为“微语主题”。它按浅色配色解析，并在同步启动阶段和实时主题呈现阶段都通过 `body[data-ds-theme='wechat']` 标识。`ui-theme/styles/wechat.css` 统一拥有作用域配色和语义组件 token；功能样式只消费这些 token，并以原有值兜底，覆盖侧栏选中态、新会话按钮、会话表面、消息气泡和输入区。

该主题借鉴微信桌面端的信息层级与绿色聊天配色，但不复制其 Logo、图标集、头像、截图或其他品牌素材。它只改变展示，不改变路由、会话、工具、权限或 Host 行为；这些仍是官方 DeepSeek Harness 的能力。用户可在“设置 > 常规 > 外观”中选择，Host 设置提供方会像其他内置主题一样持久化选择。

## 验证

GUI 测试覆盖内置注册、选择、持久化、启动属性、呈现器清理与样式作用域。Web 端到端设置场景会真实点击“微语主题”，检查 `data-ds-theme="wechat"`，并验证 `settings.yaml` 写入 `preference: wechat`。
